# BadBoy Kick v7 — دليل التحديث من الهاتف

## الملفات المطلوبة
- `index.html`: واجهة التطبيق.
- `badboy-kick-v7.js`: أدوات الشات وتوفير البيانات والجدولة والأرشيف المحلي.
- `api/kick.js`: المصادقة الرسمية، الملف العام، غرفة الشات، سجل الرسائل، الإرسال والردود والإشراف.
- `vercel.json`: مسارات الخادم.
- `package.json`: إعدادات المشروع.
- `.env.example`: أسماء المتغيرات فقط؛ لا يحتوي أسرارًا حقيقية.

## رفع النسخة إلى GitHub من الموبايل
1. نزّل ملف ZIP وفك الضغط في تطبيق الملفات على الهاتف.
2. افتح مستودع GitHub المتصل بمشروع Vercel.
3. استبدل `index.html` و`api/kick.js` و`vercel.json` و`package.json` بالنسخ الموجودة في الحزمة.
4. ارفع الملف الجديد `badboy-kick-v7.js` في جذر المستودع، بجانب `index.html` بالضبط، وليس داخل مجلد `api`.
5. اترك ملف `.env.example` اختياريًا؛ لا ترفع أي ملف يحوي قيمًا حقيقية لـClient Secret.
6. اعمل Commit، ثم افتح Vercel وانتظر انتهاء النشر. لا تغيّر Environment Variables التي ضبطتها بالفعل إذا كان تسجيل الدخول يعمل.
7. اختبر `https://اسم-مشروعك.vercel.app/api/health`؛ المفروض أن يظهر `ok: true` ولا توجد متغيرات ناقصة.
8. افتح موقع Vercel وجرب فتح قناة، تحميل السجل، إرسال رسالة، واختيار حساب الإرسال.

## ما تتضمنه النسخة
- محاولة جلب سجل الرسائل باستخدام مسار السجل الحالي ثم المسار الأقدم الذي استخدمته التطبيقات السابقة، مع مؤشرات صفحات `cursor`؛ الرسائل الواردة تُدمج مع الشات الحي ويُمنع تكرار المعرفات.
- حفظ الرسائل التي يستقبلها التطبيق في IndexedDB محليًا، مع فصل رسائل البث الحالي عن الرسائل الأقدم عندما يتوفر وقت بداية البث.
- تحسين عرض الشات الكبير وتقليل عدد العناصر الظاهرة في الذاكرة، والبحث داخل الرسائل المحمّلة، ووقت الرسالة، والردود، وصور الحسابات والستيكرات الرسمية.
- شريط للستيكرات التي سبق ظهورها، ومكتبة محلية للرسائل المحفوظة.
- مشغل HLS عندما يوفر المصدر رابط تشغيل مناسبًا، واختيار مستوى الجودة المتاح، ومحاولة ضبط الجودة حسب الشبكة؛ إذا لم يصل رابط HLS مناسب أو تعذر تشغيله، يرجع التطبيق إلى مشغل Kick المضمّن.
- قائمة انتظار للإرسال الفاشل، مع إعادة محاولة محدودة للأخطاء التي تسمح بذلك ومراجعة يدوية للحالات غير المؤكدة.
- جدولة رسائل متعددة في كل جدول (رسالة في كل سطر)، بالترتيب أو عشوائيًا، مع فاصل زمني وعدد محدد أو غير محدود. الجدولة تعمل ما دام التبويب مفتوحًا؛ لا تعمل بعد إغلاق المتصفح.
- سجل أحداث وإحصائيات، ونسخة احتياطية مشفّرة واستعادة للأرشيف والإعدادات المحلية.
- صفحة «توفير البيانات» مع مفاتيح فعّالة لإيقاف الفيديو والشات وجلب التاريخ والصور والستيكرات، وتأجيل تشغيل الفيديو، وتقليل الطلبات والحركة.
- زر «نسخ التوكن» ينسخ توكن الوصول للحساب الرسمي المحدد في قائمة الإرسال. لا ترسله لأحد، ولا تضعه في GitHub أو داخل صور الشاشة.

## ملاحظات موثوقية
- فُحصت صياغة JavaScript وJSON، واختُبر مسار الخادم التاريخي محليًا ببيانات اختبار لمحاكاة الرجوع إلى مصدر السجل الأقدم والتعامل مع `cursor`. هذا لا يُعد اختبارًا حيًا لخادم Kick أو لحسابك.
- بعض طرق قراءة سجل الشات التي استخدمتها التطبيقات السابقة غير موثّقة كواجهة عامة مضمونة. سيحاول التطبيق أكثر من مسار، لكن لا يمكن ضمان استرجاع كل الرسائل منذ إنشاء القناة أو الرسائل التي لم تعد Kick توفرها.
- مصدر HLS والجودة يتوقفان على توفر رابط تشغيل صالح ودعم المتصفح؛ عند تعذرهما يستخدم التطبيق مشغل Kick الرسمي المضمّن.
- لا تُضاف في هذا الإصدار قواعد تلقائية للشات.
- لا تغيّر `KICK_CLIENT_SECRET` ولا تضعه في HTML أو المستودع. احتفظ به في Environment Variables على Vercel فقط.
